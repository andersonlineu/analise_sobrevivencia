## Sobre o material

Este repositório apresenta um guia didático para leitura e interpretação dos resultados de modelos de sobrevivência ajustados no **R** com a função `coxph()` do pacote `survival`.

O conteúdo foi desenvolvido para estudantes, pesquisadores e profissionais que desejam compreender de forma prática os principais elementos apresentados por:

```r
summary(coxph())
```

## Conteúdo

* construção do objeto `Surv()`;
* estrutura da saída de `summary(coxph())`;
* interpretação do **Hazard Ratio — HR**;
* coeficientes e erros-padrão;
* intervalos de confiança;
* testes de Wald, razão de verossimilhança e escore;
* concordância do modelo;
* comparação de modelos aninhados;
* roteiro prático para leitura dos resultados.
